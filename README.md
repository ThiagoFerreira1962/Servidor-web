## Tecnologías 
- **Lenguaje:** Java 24
- **Build:** Apache Maven
- **Servidor web:** Apache Tomcat (versión 11)
- **Backend web:** Jakarta Servlets (`jakarta.servlet`)
- **Interfaz de escritorio:** Swing
- **Frontend web:** HTML y CSS
- **Testing:** JUnit (versión 5)
- **Calidad de código:** PMD y Checkstyle

 ## Requisitos
- JDK 24
- Maven 3.9+
- Tomcat 10.1 o superior (necesario para `jakarta.servlet`)
